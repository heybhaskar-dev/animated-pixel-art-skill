# Prompt Recipes

## Expressive cozy object
Animate this transparent pixel-art asset into a premium seamless idle loop. Keep the original design, palette, composition, and pixel density. Make the focal character/object feel alive with blinking, subtle breathing, squash-and-stretch, expression changes, secondary accessory motion, restrained environmental motion, pulsing light, and particles. Preserve transparency and crisp pixel edges.

## Mountain lake landscape
Turn this pixel-art mountain-and-lake scene into a calm seamless ambient loop. Keep mountains stable. Animate lake reflection shimmer, horizontal glints, slow clouds, distant mist, subtle foreground tree movement, occasional tiny birds, and restrained parallax. Avoid warping the mountain silhouettes.

## Wow loop
Create a more expressive premium loop using anticipation, action, overshoot, follow-through, and settle. Give important elements independent timing. Add one memorable moment near the middle, then return naturally to the neutral state.
